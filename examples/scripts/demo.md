# AI Card Video Pipeline

A card-video workflow should start from one clear script and end with a reusable MP4. The content should stay editable, the renderer should stay local, and the visual style should be selectable.

- Write the story once in markdown or JSON.
- Choose a style such as Bauhaus, Art Deco, Pop Art or Y2K.
- Render the same spec through HyperFrames or Remotion.
- Export posters, keyframes and style previews before final delivery.

1. Plan the video spec from the script.
2. Validate structure, timing and readability.
3. Preview the visual direction.
4. Render the final MP4 with prepared audio.

The upgraded skill supports 16 styles, 4 formats and 2 render engines. It remains local-first and agent-friendly.

Use it to make repeatable knowledge videos, product explainers and short social clips without manual editing.
